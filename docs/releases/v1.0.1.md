## 下载与安装

适用于 **Apple Silicon（M 系列）Mac**。下载下方的 `HermesEnabler-Installer-1.0.1-macOS-arm64.dmg`，打开后把 `HermesEnabler-Fixed.app` 拖入「应用程序」。无需安装 Rust 或自行编译。

- 最低构建目标：**macOS 13**；本次在 macOS 27.2.1 验证，未在 macOS 13 真机验证。
- 仍需完整 **Xcode**，放在 `/Applications/Xcode.app`；只有 Command Line Tools 不够。
- 本包不包含 HermesEnabler IPA，请从 [原作者 Releases](https://github.com/pookjw/HermesEnabler/releases) 下载。
- 本次没有 Intel 预编译包。

应用采用 **ad-hoc 签名，未使用 Developer ID 签名，也未经 Apple 公证**。若首次打开被系统阻止，核对下载来源及校验值后，在「系统设置 → 隐私与安全性」按提示打开。无需关闭全局 Gatekeeper 或 SIP。DMG 内附中文安装说明及许可证。

## 修复内容

- Apple 开发者接口在连接阶段失败时按 1、2、4 秒重试，最多 4 次尝试；增加连接和请求超时，保留证书校验。
- 移除写死的手表 UDID，改为用户从界面或 `WATCH_UDID` 输入自己的标识。
- 手表注册或 `devicectl` 安装失败时正确报告失败。
- 清理重复运行时的验证码状态，增加无需登录的网络检查。
- 修正 GUI 的最低系统构建目标，避免默认按构建机器的 macOS 27.2 编译。
- 补充 Device Hub 配对、UDID 获取和常见错误排查。

## 验证与限制

已完成 release 构建、17 项回归测试、应用签名完整性与架构检查、DMG 校验及只读挂载检查。最低系统支持以构建目标为准，不代表已经覆盖所有旧版系统。

完整账户签名、Watch 安装和表盘修改仍需在用户自己的设备上完成。当前证书策略可能在额度不足时吊销旧开发证书，影响同证书签名的其他应用；操作前请阅读 [README](https://github.com/hoky/hermesenabler-installer#readme)。

## 校验下载

将 DMG 和 `SHA256SUMS.txt` 放在同一文件夹，然后运行：

```bash
shasum -a 256 -c SHA256SUMS.txt
```
